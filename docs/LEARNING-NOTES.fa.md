# یادداشت‌های یادگیری پروژه Salesly

خلاصه‌ی مراحل ساخت این پروژه و مفاهیمی که در هر مرحله به کار رفته‌اند.

## مرحله ۱ — راه‌اندازی
- **Vite**: سرور توسعه و ابزار ساخت. خیلی سریع‌تر از Create React App.
- **TypeScript**: جاوااسکریپت با نوع داده. خطاها را قبل از اجرا می‌گیرد.
- **Tailwind CSS**: استایل با کلاس‌های آماده، کنار خود کامپوننت.
- نسخه‌ی پکیج‌ها در `package.json` دقیق ثابت شده تا نصب روی هر سیستمی یکسان باشد.
- **Design Tokens**: رنگ‌ها و فونت‌ها یک‌جا در `@theme` فایل `index.css` تعریف شده‌اند.

## مرحله ۲ — پایه‌ها
- **تعریف نوع داده‌ها** (`data/types.ts`): شکل هر داده مشخص است.
- **داده‌ی نمونه با بذر ثابت** (`data/mock.ts`): «تصادفی‌نما» ولی هر بار یکسان.
- **Context**: دسترسی سراسری به زبان و تم بدون پاس دادن دستی (prop drilling).
- **ترجمه‌ی تایپ‌شده**: `t('nav.orders')`؛ کلید اشتباه = خطای کامپایل.
- **Intl**: ارقام فارسی و تاریخ شمسی بدون کتابخانه‌ی اضافه.
- **useReducer**: مدیریت افزودن/ویرایش/حذف محصول (ایده‌ی Redux بدون نصب آن).

## مرحله ۳ — قالب و مسیریابی
- **SPA** و **React Router**: یک صفحه‌ی HTML، جابه‌جایی بدون رفرش.
- **Outlet**: جای محتوای هر صفحه داخل قالب مشترک.
- **وضعیت در URL**: جستجو در آدرس (`?q=...`) ذخیره می‌شود و قابل اشتراک است.
- **کلاس‌های منطقی** (`ms-`, `ps-`, `start-`): چیدمان در RTL خودکار آینه می‌شود.
- **DRY**: کامپوننت‌های قابل استفاده‌ی مجدد در `components/ui`.

## مرحله ۴ — داشبورد
- **Separation of Concerns**: محاسبات در `lib/stats.ts`، نمایش در کامپوننت‌ها.
- **Recharts**: نمودار ناحیه‌ای، دونات، اسپارک‌لاین.
- نمودارها در RTL برعکس می‌شوند (`reversed`، محور سمت راست).
- **Mobile-first grid**: `grid sm:grid-cols-2 xl:grid-cols-4`.

## مرحله ۵ — جدول سفارش‌ها
- **Headless UI**: TanStack Table فقط منطق می‌دهد؛ ظاهر دست ماست.
- جستجو، فیلتر، مرتب‌سازی، صفحه‌بندی، خروجی CSV (با BOM برای اکسل).
- **useMemo**: جلوگیری از محاسبه‌ی تکراری.
- **دسترس‌پذیری**: `aria-sort`، `role="tab"`.

## مرحله ۶ — CRUD و فرم
- **فرم کنترل‌شده** + اعتبارسنجی + نمایش خطا.
- **key** برای ساخت دوباره‌ی فرم با هر بار باز شدن.
- **localStorage** برای ماندگاری تغییرات (داخل try/catch).
- **Toast** و **Modal** با Escape و قفل اسکرول.

## مرحله ۷ — نسخه‌ی نهایی
- **Code Splitting** با `React.lazy`: حجم بارگذاری اولیه از ۶۸۰ به ۲۵۰ کیلوبایت رسید.
- `vercel.json` برای کار کردن لینک‌های مستقیم بعد از انتشار.

## دستورها
```bash
npm install      # نصب وابستگی‌ها (فقط بار اول)
npm run dev      # اجرا در حالت توسعه
npm run build    # ساخت نسخه‌ی نهایی
```
